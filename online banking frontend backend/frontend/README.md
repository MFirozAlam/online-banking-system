# Online Banking System - Frontend

## Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Run
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

The Spring Boot backend must be running on `http://localhost:8080`.

## Implemented
- User registration
- Login/logout
- Create Savings/Current account
- View account
- Deposit
- Withdraw
- Transfer between accounts
- Transaction history
- Transaction type filter
- Delete account
- Validation and API error messages
